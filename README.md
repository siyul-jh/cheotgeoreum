# 첫걸음

하고 싶은 일을 적어 두는 버킷리스트 앱. 막막한 칸은 AI가 초안을 채워 주고, 적은 꿈은 별 카드로 공유한다.

https://cheotgeoreum-app.vercel.app

## 기능

- **단계별 작성**: 항목 → 이유 → 카테고리 → 목표 시기 → 선행 과제 → 다음 행동 → 함께할 사람 순서로 한 칸씩 정한다
- **AI 도움**: 뭘 적을지 모르면 아이디어를 추천받고, 비어 있는 칸은 [빈 칸 채우기]로 초안을 받아 고쳐 쓴다
- **오늘의 첫걸음**: 목록 위에서 지금 할 다음 행동 하나를 보여 준다
- **별 카드**: 저장한 꿈을 카드로 보여 주고, 이미지로 저장하거나 짧은 링크로 공유한다. 받은 사람은 설치 없이 카드를 본다
- **로그인(선택)**: 구글·카카오로 로그인하고, 설정에서 다른 쪽도 연결하면 어느 쪽으로 들어와도 같은 계정. 로그인하면 꿈 목록이 계정에 저장돼 다른 기기와 맞춰진다
- **목록 공유**: 고른 꿈 목록을 짧은 링크 하나로 나눈다
- **설정**: 계정(연결·로그아웃·삭제), 화면 모드(라이트·다크·시스템), 내 카테고리(추가·이름 바꾸기·삭제), 데이터 내보내기·가져오기

## 설치

배포 주소는 **설치한 앱으로 열어야** 쓸 수 있다. 브라우저로 열면 설치 안내가 나온다.

- 아이폰·아이패드: Safari 공유 버튼(□↑) → 홈 화면에 추가
- 안드로이드·PC 크롬 계열: [앱 설치] 버튼
- Mac Safari: 파일 → Dock에 추가

## 데이터

- 로그인하지 않으면 꿈 목록은 **기기 안(localStorage)에만** 저장된다. 아이폰은 Safari와 홈 화면 앱도 서로 다르다
- 로그인하면 꿈·내 카테고리가 계정(Neon)에 저장되고, 같은 계정으로 로그인한 기기끼리 자동으로 맞춰진다(더 나중에 고친 쪽이 남는다). 처음 연결할 때 기기에 있던 꿈은 옮길지 묻는다
- 맞추면 이 기기의 꿈이 크게 줄어드는 경우(다른 기기에서 절반 이상 지움 등)는 적용을 멈추고 설정에서 묻는다
- 백업: 설정 → [데이터 내보내기]로 JSON을 받고 [가져오기]한다. 가져오기는 꿈을 더하고 같은 꿈은 덮어쓴다
- 계정을 삭제하면 서버의 계정·꿈이 지워진다. 기기 안의 꿈은 남는다
- 공유한 카드·목록 내용만 짧은 링크용으로 서버에 1년 보관된다

## 개발

```sh
yarn install
cp .env.example .env   # 값 채우기
yarn dev
```

DB는 Postgres(Neon)에 `db/auth-schema.sql` → `db/schema.sql` 순서로 적용한다. 테이블이 없으면 로그인 API가 500을 낸다. 서버 동기화 테스트는 PGlite(WASM Postgres)에 같은 스키마를 올려 돈다

검사: `yarn typecheck && yarn lint && yarn test && yarn build && yarn check:bundle` (GitHub Actions에서도 같은 순서로 돈다)

- 개발 서버에서는 설치 안내 없이 바로 열린다
- `.env`는 커밋하지 않는다
- `yarn dev --host`로 LAN에 열면 같은 네트워크의 누구나 AI 기능을 호출할 수 있다. 믿을 수 있는 네트워크에서만 잠깐 연다
